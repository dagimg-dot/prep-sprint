## The Hard Truths (Gathered from Hundreds of Real Success Stories)

From [r/IELTS](https://reddit.com/r/IELTS), [CanadaVisa forums](https://www.canadavisa.com/canada-immigration-discussion-board/), [IELTS-Blog](https://www.ielts-blog.com/), and personal accounts from India, Vietnam, Pakistan, Philippines, Uzbekistan, Bangladesh, Morocco, and Nigeria:

1. **Band 7+ in <30 days IS possible** — but only if you're already around B2 (Band 6–6.5 equivalent). If lower, this plan still maximizes your score.
2. **Writing is ALWAYS the bottleneck** — 90% of plateau stories trace back to Writing. Most self-studiers score 0.5–1.0 lower in Writing than other sections.
3. **Review > Practice** — doing 50 tests without reviewing mistakes yields nothing. The people who jumped bands spent 50% of their time analyzing errors.
4. **Speaking alone is awkward but mandatory** — the ones who recorded themselves daily jumped 0.5–1.0 bands. The ones who avoided it stayed stuck.
5. **Free resources are ENOUGH** — Cambridge PDFs + YouTube channels + AI feedback tools cover 80%+ of what you need. Coaching is not required.

- [ ] Score yourself (Listening/Reading = raw count; Writing/Speaking = self-assess vs descriptors)

## ⚡ Quick Reference Cheat Sheet

### Listening
- Read questions FIRST before audio starts (you get time — use it)
- Watch for: plurals, spelling, capital letters (proper nouns)
- Section 4 is hardest — practice with [TED Talks](https://www.ted.com/talks) at 1.25x speed
- If you miss one → let go. Don't lose two.
- Never leave blank (no penalty for wrong answers)
- Practice on [ieltsonlinetests.com](https://ieltsonlinetests.com/ielts-exam-library) — has 80M+ test attempts with detailed explanations

### Reading
- **15min P1 → 20min P2 → 25min P3** (hardest passage gets most time)
- DON'T read passage first → skim 2min, go to questions
- True/False/Not Given: if text doesn't say it → Not Given (even if logically true)
- Matching Headings: read 1st sentence of each paragraph → match
- Practice at 18min/passage to build speed buffer
- Use [ieltstestsimulation.com](https://www.ieltstestsimulation.com/) for auto-corrected tests with band calculation

### Writing Task 2 (Essay — 40 min)

```
5min PLAN → 30min WRITE → 5min REVIEW

Structure:
  - Intro (paraphrase + position)
  - Body 1 (point + explain + example)
  - Body 2 (point + explain + example)
  - Conclusion (summary)

Target: 270–300 words
```

**Golden rule from ex-examiners:** Clear structure + specific examples + error-free sentences > fancy words.
Get essays graded at [engnovate.com](https://engnovate.com/) or [ielts-gpt.com](https://ielts-gpt.com/).

### Writing Task 1 (Report — 20 min)
- **ALWAYS include an overview paragraph** (this is what separates 6.5 from 7)
- Describe key trends, NOT every data point
- Use comparative language (while, whereas, in contrast)
- Practice prompts on [ielts-up.com](https://ielts-up.com/writing/ielts-academic-task-1.html)

### Speaking (11–14 min)
- **Part 1 (4-5 min):** Give 2-3 sentence answers, not one word
- **Part 2 (3-4 min):** Use 1-min prep to write 4-5 keywords. Speak for full 2min
- **Part 3 (4-5 min):** Give reasons + examples + contrasts
- Record yourself DAILY — listen back for filler words, hesitations, repeated vocab
- Use [ielts-up.com speaking simulator](https://ielts-up.com/ielts-speaking-simulator.html) for realistic practice
- **Natural > memorized.** Examiners detect scripts and penalize.

1. **You don't need coaching.** Every resource above has a direct link and is free. Thousands from developing countries have proven this works.

   - Skip hard questions, come back
   - No negative marking → guess everything
   - Stay calm in Speaking — the examiner wants you to succeed
   - Computer-based: practice typing speed at [typing-test.com](https://typing-test.com/)
